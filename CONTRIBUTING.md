# Repository language

Call independently identified Workspace collaborators **Peers**. Reserve
subagent for host-local delegation, and distinguish protocol roles from Peer
identities. Preserve declared role IDs, wire fields and public SDK symbols; see
[Peer terminology](docs/peer-terminology.md).

Use English for project-authored source identifiers, file names, comments, docstrings,
documentation, scripts, test descriptions, user-facing text, and commit/release
descriptions. Apply the same convention when maintaining historical documents.

Unicode test inputs, frozen experimental inputs, third-party files and verbatim
evidence are data.
Preserve their exact meaning or bytes where required and explain their purpose
in English. Keep published source tags and signed artifacts immutable.

Keep operator reports, private environment details, local build records and
internal handoffs outside the public repository. Public examples must be usable
from a fresh clone with documented parameters and generic paths. Preserve
functional Unicode test data and upstream license/locale content.
