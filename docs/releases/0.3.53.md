# Native SDK 0.3.53

An existing Codex Bridge can recover delivery to the original thread when its
pinned App Server no longer loads that thread or reports another writer. This
applies to a protected local queue-capable Codex installation pinned to the
same OS user and exact thread. The Bridge uses Codex's durable local queue for
compact inbox references and retains its original configuration, identity and
admission records.

The Bridge preserves accepted, queued and uncertain notification results when
the transport changes. It can retry a proven no-input attempt. A failed
read-only preflight is recorded separately from an uncertain input write.

The package targets Linux x86_64 GNU.
