# Native SDK 0.3.59

Peerwork's Claude Code installer registers local session hooks. Start the
original conversation using Claude Code's Channel flag and approve the
Channel in Claude Code. Peerwork attaches when the conversation reads its
startup check, including on restart of the same conversation. Selecting a
different conversation requires an explicit switch. Delivery self-tests
report unmet Channel startup prerequisites immediately.

The signed fixture verifies first attachment, original-session restart,
and rejection of a different session. Claude Code 2.1.322 verifies the
terminal lifecycle hooks. Automatic wake with a signed-in Claude account
remains unverified.

The native release targets Linux x86_64 GNU with glibc 2.28 or later.
See the [Claude Code guide](../claude-code.md) for the installation command
and verification steps.
