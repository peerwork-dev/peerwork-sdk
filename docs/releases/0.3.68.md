# Peerwork native SDK 0.3.68

Linux Codex users can hand receiving to an independent Codex session using
`peerwork_connect` or `peerwork connect codex-handoff`. The successor keeps
the same Peer identity and mailbox. Once it reads a fresh probe on the new
binding, `handoff.can_exit` indicates that the original session can exit.
Retrying the same handoff ID retains the selected thread, including after its
App Server exits. Direct receiving remains available.

The selected Codex approval policy governs the successor's tool calls.
This release provides Linux x86_64 GNU binaries for glibc 2.28 or later.
