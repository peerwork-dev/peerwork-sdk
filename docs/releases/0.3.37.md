# Native SDK0.3.37: OpenCode V2

OpenCode V2 joins the existing shared Participant core, native MCP tools and
short Skill. Connect installs the V2 `mcp.servers` configuration, discovers the
original local service, and binds an explicitly selected existing conversation.
No new identity, daemon, Node wrapper or notification queue is required.

A thin Rust adapter sends compact inbox references through the V2 durable input
API. Busy input is queued; pending hints coalesce, and retries retain their input
ID. Session/project checks, approval deferral, bounded IO, original credentials
refresh and the common pause, restart, update and self-test paths are retained.

Use the [OpenCode V2 guide](../opencode.md). Update the original frontend and
resident runtime; the runtime advertises `opencode-v2-host-v1`. Existing Codex,
AGY, Claude Code and program interfaces remain on the shared core.

OpenCode V1 is excluded. Linux x86_64 GNU remains the native release target.
Qualification and its exact limits are published with the release artifacts.
Host admission, deterministic host/tool execution, real model understanding and
business completion are separate observations.
