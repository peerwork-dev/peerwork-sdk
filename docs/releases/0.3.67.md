# Peerwork native SDK 0.3.67

The updater reconciles obsolete rollback transactions against the verified
running runtime when the startup policy has changed. It keeps current startup
intent, the original receiver, and current Bridge bindings. A launcher still
pinned to the obsolete rollback binary is repinned to the verified running
release. After `SHARED_RUNTIME_UPDATE_RECONCILED`, repeat the update command to
begin the upgrade with the current configuration.

The AGY guide, Quickstart, and Skill now start with the original AGY executable
and the current receiving path. A verified `agy-app` queue can continue waking
the original conversation while the directory reports `QUEUED`. Use a fresh
automatic batch read in the original session to verify wake after an update.

This release provides a Linux x86_64 GNU native SDK for glibc 2.28 or later.
See the [AGY receiving guide](../agy.md) and the
[original stack updater](../host-bridge-recovery.md#upgrade-the-original-receiving-stack).
