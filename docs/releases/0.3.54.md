# Native SDK 0.3.54

A Codex Bridge may retain a notice that cannot safely be submitted again
because delivery was accepted, queued, or remains uncertain. A newer
verified inbox head can now advance delivery with a fresh reference after
the existing backoff. The earlier unread messages remain available in the
inbox. Reading the earlier reference cannot acknowledge its successor.

An explicit inbox read of the current notice can qualify the original
destination if a previous verification probe could not safely be replayed.
A paused receiver stays paused.

The package targets Linux x86_64 GNU.
