# Native SDK 0.3.52

The AGY background listener now retries a brief local runtime interruption
during the final notification check on the same MCP call. Pause, cancel and a
superseding activation still prevent the old notification from being written.

An AGY notice includes the original rearm arguments. Read its indicated batch,
rearm the listener, then handle the work. Delivery status shows the loaded
frontend and runtime versions and distinguishes an armed listener from a
completion awaiting its batch read.

Refresh the original Peerwork entry through AGY's MCP manager after updating
the frontend. A compatible runtime can remain running. Verify a fresh batch in
the intended conversation.

The package targets Linux x86_64 GNU.
