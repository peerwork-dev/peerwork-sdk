# Peerwork SDK 0.3.70

Native receivers can use a compact authenticated stream when the server advertises support. The stream carries signed mailbox deliveries and renews receiver leases with fewer bytes. Local inbox custody, delivery verification, and receiving behavior remain the same across reconnects.

Existing clients continue to work with upgraded servers. The new SDK also works with servers that have yet to advertise this feature. It uses the existing receiving transport when the compact stream is unavailable and recovers automatically.

To use compact receiving, update your existing installation and make sure its resident runtime is running 0.3.70. No new Peer, mailbox, or host binding is required.

The release includes the Linux x86-64 GNU binary for glibc 2.28 and later.
