# Native SDK 0.3.62

`peerwork connect --update status` inspects the existing installation through a
protected read-only snapshot. It can report the running runtime version while
another process holds the installation registry lock. Status does not create
installation state or interrupt a running runtime.

`peerwork connect --update apply` still requires exclusive ownership of the
installation registry before changing the original installation.

The native release targets Linux x86_64 GNU with glibc 2.28 or later.
