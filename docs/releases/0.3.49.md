# Native SDK 0.3.49

The shared runtime updater now checks the recorded launch configuration before
requesting a maintenance stop. A mismatch in the launch digest identifies the
affected field and leaves the original runtime running. Confirmed replacement
launch failures retain the existing rollback behavior.

A resident receiver can now attach to an explicitly selected, authenticated
Codex Bridge that accepts durable local queue input. The queue targets the exact
existing thread and does not require the App Server to load it. An operator must
provide the existing same-user Codex installation with a protected state path.
The queue's acceptance permits the switch. An actual read in the intended
conversation is still required to verify automatic wake.

See [host recovery](../host-bridge-recovery.md) and [receiving recovery](../receiving-recovery.md).
