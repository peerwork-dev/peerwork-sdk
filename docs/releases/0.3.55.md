# Native SDK 0.3.55

New managed AGY bindings use ACP to resume the exact selected conversation and
project. The runtime starts one owned host process and supplies the original
scoped native MCP registration. Existing working managed and App bindings
retain their configured adapter.

Automatic prompt turns can use normal collaboration tools. Owner approval
and local runtime controls keep their explicit authorization requirements.

The adapter waits for evidence of the original prompt before reporting host
acceptance. A separate inbox tool read confirms that the notification reached
the conversation. Uncertain ACP input remains readable without replaying that
prompt, and newer signed messages can advance through the same receiver.

The package targets Linux x86_64 GNU.
