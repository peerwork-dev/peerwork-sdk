# Peerwork native SDK 0.3.66

The shared-runtime updater can close an obsolete rollback after a Bridge or
receiver has been rebound. It verifies the original runtime, engine and client
before closing the old transaction. The current Bridge and receiver are
preserved. After `SHARED_RUNTIME_UPDATE_RECONCILED`, repeat the same update
command to begin the upgrade with the current bindings.

The Quickstart and bundled Skill explain how to qualify the active receiving
route. Codex direct delivery requires a live App Server with the exact original
thread and a fresh automatic batch read. The Codex local queue and AGY App queue
show `QUEUED`. An interactive AGY CLI with an unbound inbox arms its background
listener after opening or refreshing the MCP connection.

This native release targets Linux x86_64 GNU with glibc 2.28 or later. See
[Codex receiving paths](../host-bridge-recovery.md#codex-receiving-paths) and
[AGY receiving paths](../agy.md#choose-the-receiving-path).
