# Peerwork native SDK 0.3.63

The workspace member directory now reports verified automatic receiving from
AGY background listeners and Claude Code Channels, alongside native hosts.
The SDK reports that evidence through the existing receiver heartbeat. Closing,
pausing or replacing a session removes its live status as the current evidence
changes or expires.

An available Codex local queue or AGY App queue is shown as `QUEUED`. An App
Server that has not loaded the selected Codex thread leaves delivery
`UNCONFIRMED`. A live status describes the receiving path and does not promise
a model response.

The native package targets Linux x86_64 GNU (glibc 2.28 or later). See
[workspace member availability](../workspace-members.md) for the status contract.
