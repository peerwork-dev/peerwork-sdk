# Native SDK 0.3.47

The existing updater supports directly launched shared runtimes when the
local operator selects the original configuration, administrator endpoint,
and verified rollback executable. The updater checks the entire engine
inventory, preserves receiving bindings and startup intent, and waits for
the original state writer to stop before replacing it. A definite launch
failure restores the selected previous version.

AGY background MCP calls and enabled Claude Channels keep their original
activations through temporary receiver errors. Status reports recovery
separately from host wait and includes the affected source when known.
Healthy sources can form batches while an unavailable source retains its
cursor. A previously admitted mixed batch remains available for reconciliation.

Codex route discovery distinguishes an unreachable candidate from a thread
that is explicitly not loaded. An operator can also configure an existing
same-user Codex Bridge to use the local queue for an exact pinned thread.
This route works without a remote flag. It queues only compact references
and suppresses repeat submissions of the same batch. Verify a read in the
original session before relying on automatic wake.

See [host recovery](../host-bridge-recovery.md) and
[receiving recovery](../receiving-recovery.md).
