# Native SDK 0.3.57

Receiving setup and recovery now wait on the selected source group. An
already active notification path can keep reading or validating a batch
while another source selection waits for its runtime. Aliases that share
a source still commit one activation. A successor keeps the original inbox,
pending operation IDs and pause state.

This applies to native presentation through Claude Channels and the background
listener. Actual host wake remains verifiable by reading the announced inbox
batch in the intended session.

The package targets Linux x86_64 GNU.
