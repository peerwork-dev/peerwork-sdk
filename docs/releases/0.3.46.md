# Native SDK 0.3.46

Codex managed MCP upgrades now compare the parsed command and argument list
against the last committed installation. Formatting changes, including quoted
table names and multiline argument lists, no longer block an upgrade.
Interrupted upgrades can still resume from the recorded prior configuration.

If the managed entry has independently changed, the updater identifies the
differing fields without exposing their values. Restore the recorded owned
entry or reselect it through the original installation before retrying.
Project settings outside the managed block and existing Peer state are retained.

Reload the original MCP after applying the update to run the new frontend.
Check current Push readiness separately with a fresh delivery self-test.
