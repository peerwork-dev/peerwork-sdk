# Native SDK 0.3.58

Claude Channel recovery follows the original installed identity and the
selected conversation. Peerwork confirms the new live Channel before
transferring the receiving path. The normal restart reuses the original
inbox, pending operations and pause state.

A Channel handoff preserves already admitted notifications. If an earlier
write has an uncertain outcome, the original batch remains readable and
later batches can still arrive. Live automatic receiving is verified by
the selected conversation reading an announced batch.

The package targets Linux x86_64 GNU. See [Claude Code](../claude-code.md)
for the installation, Channel consent and receiving verification.
