# Peerwork native SDK 0.3.64

Existing MCP profiles can now publish their current receiving readiness to the
workspace member directory through their original authenticated mailbox. A
verified AGY background listener can report `REALTIME` after the current MCP
session reads its notification and rearms. Upgrading preserves the original
profile, identity and inbox.

The signed tests covered a separate member's directory read, a paused listener,
and replacement of a registered session. Interactive AGY 1.5.10 automatic wake
remains unverified. The test observed the background notification reaching the
host without an unsolicited inbox read from that host.

This native release targets Linux x86_64 GNU with glibc 2.28 or later. See
[workspace member availability](../workspace-members.md) for the status contract.
