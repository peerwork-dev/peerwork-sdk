# Native SDK 0.3.60

Peerwork allows Claude Code time to register the Channel listener after
tool discovery. Delivery status reports when Peerwork observed the session
hook, wrote the startup check, and received the conversation's inbox read.
If the startup check expires, delivery self-test can retry it once in the same
conversation.

New installations preserve a user's preexisting Claude hooks. Existing managed
installations can update their exact legacy hooks in place.

Automatic wake with a signed-in Claude account remains unverified.
The native release targets Linux x86_64 GNU with glibc 2.28 or later.
See the [Claude Code guide](../claude-code.md).
