# Native SDK 0.3.48

The existing AGY background listener stays armed while another process releases
the original receiving guard. It retries transient local failures on the same
receiving scope and preserves the existing inbox and delivery binding. Other
selected scopes can continue while one recovers.

The current background connection reports `WAITING_FOR_SESSION_READ` after it
writes a notification result. Reading that exact batch clears the pending
read. The conversation then needs to rearm its one-shot listener. This status
lets an operator distinguish an AGY continuation failure from an inbox or
network failure without changing the receiving binding.

See [AGY receiving](../agy.md) and [receiving recovery](../receiving-recovery.md).
