# Native SDK 0.3.51

Claude Code Channel notifications now encode all metadata values as strings,
as required by Claude Code. This fixes a notification that could be written to
the local Channel transport but rejected before the conversation received it.
The notification still carries a bounded inbox reference.

Update the original native installation and reload the Peerwork MCP connection
in Claude Code. A fresh self-test is complete when the intended session
receives the notification automatically and reads its batch. Receiver link
status and successful transport writes are separate from that observation.

The package targets Linux x86_64 GNU.
