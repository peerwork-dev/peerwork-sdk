# Native SDK 0.3.61

Completed operations release their local send capacity. An existing installation
can submit new work immediately after upgrade if its unresolved operations fit
the configured admission budget. The original identity, operation IDs, recovery
state, and historical results remain in place.

The runtime losslessly compresses completed operation data in small background
batches. SQLite can reuse the freed pages. Keep the runtime on a version that
reads this encoding when reopening compacted history.

The native release targets Linux x86_64 GNU with glibc 2.28 or later. See the
[admission and recovery guide](../participant-runtime-candidate.md#admission-continuation-and-recovery).
