# Peerwork native SDK 0.3.65

The shared-runtime updater can close a stale `ROLLING_BACK` transaction when
the original runtime is already running on a compatible version. Run `update
apply` with the same protected configuration and administrator endpoint, and
select the verified binary of the running version as the rollback executable.

The updater verifies the existing bindings before returning
`SHARED_RUNTIME_UPDATE_RECONCILED`. Closing the transaction keeps the runtime
running and leaves the operation history intact. Repeat the same command to
begin the new update. The original transaction is retained if its live binding
or running version cannot be verified.

This native release targets Linux x86_64 GNU with glibc 2.28 or later. See the
[shared runtime upgrade guide](../host-bridge-recovery.md#upgrade-a-directly-launched-shared-runtime).
