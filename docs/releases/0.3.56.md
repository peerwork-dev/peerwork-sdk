# Native SDK 0.3.56

The resident receiver requests a compact signed mailbox lease response. Each
renewal keeps the existing schedule, signature verification, and recovery
behavior. Caller-initiated mailbox reads still return the full mailbox.
The runtime also accepts the full signed renewal response from services that
ignore the HTTP preference.

In the paired service qualification, 600 renewals used 49.1% fewer response
body bytes and 28.5% fewer combined request and response body bytes at the
existing six-second cadence. This measures JSON bodies on a synthetic Peer.

The package targets Linux x86_64 GNU.
