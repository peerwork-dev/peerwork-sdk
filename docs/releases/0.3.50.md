# Native SDK 0.3.50

Verified publication and Changelog reads now return exact record short links
when the paired service advertises `short-record-locators-v1`. A short link
selects one immutable record revision. The service still checks visibility and
account access when opening it. Existing long links retain their exact targets.

The SDK continues to generate compatible long links for a service that has not
advertised short record links. The offline URL builder accepts
`short_record_links: true` for a known supporting service.

See [browser locators](../backend-structure-workspace-locators-candidate.md).
