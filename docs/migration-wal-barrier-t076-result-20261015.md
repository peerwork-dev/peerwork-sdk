# T076 metadata-only WAL barrier qualification

The new own-child tracer is qualified for the narrow Linux/x86_64 test-control boundary. It follows one synchronous child, arms only after a successful `fsync` on the selected backup descriptor, matches the selected WAL path through `/proc/<child>/fd/<fd>`, and kills only at `pwrite64` entry for an eligible payload after successful WAL-header and frame-header writes. It records descriptor/path-match booleans, offsets, counts, syscall returns, arm/header flags, and terminal status. It does not read child memory or write buffers and does not trace unrelated processes or threads.
