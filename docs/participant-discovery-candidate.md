# First-use discovery and current-session support

Native0.3.4 shared-project onboarding is documented in the canonical
[connect guide](participant-connect.md), including protected OS-user state,
original-registry confirmation and exact local diagnostics. Follow that guide
only with its matching published binary; source branches do not establish release
availability. Native0.3.3 retains its [versioned guide](participant-connect-0.3.3.md).

## Current host support

See the [host support table](participant-connect.md#current-host-support).
Tools installed, receiver custody, host acceptance and an actual model response
remain distinct. Generic automatic attachment to an arbitrary existing Codex
thread and external push into an arbitrary interactive AGY CLI are not established.
The local owning-host callback API requires an actual supported integration;
no replacement model/session is launched as fallback.
