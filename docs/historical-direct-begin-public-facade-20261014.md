# Historical direct BEGIN public facade (source candidate)

The frozen Rust operation in `secure_owner_attach.rs` accepts one caller-selected f828 direct-install BEGIN. It reads the protected TS state, intent DB and Owner PEM named by `HistoricalOwnerAttachInput`, verifies full caller-supplied package material and resolved install options against the saved intent and signed workspace replay, and reports only the selected command ID, instance ID, intent hash, original commit hash, whole TS-state digest and observed status. Inspection does not attach or POST. The caller must retain the exact inspected command ID and digest for attachment; attachment imports protected copies without a POST, and recovery names the same saved command ID. `APPLIED_IN_SIGNED_REPLAY` is an observation about the old BEGIN, not permission to skip signed continuation or native readback. Ordinary direct installation remains separate.

Python `inspect_pending_direct_install_begin`, `attach_pending_direct_install_begin` and `recover_pending_direct_install_begin` have corresponding async methods with the existing cancellation wrapper. Node exposes `inspectPendingDirectInstallBegin`, `attachPendingDirectInstallBegin` and `recoverPendingDirectInstallBegin`, each forwarding `AbortSignal`. CLI exposes `secure owner-direct-begin-inspect CONFIG INPUT COMMAND_ID OPTIONS_JSON_FILE MATERIAL_JSON_FILE`, `owner-direct-begin-attach CONFIG INPUT COMMAND_ID INSPECTED_TS_STATE_DIGEST OPTIONS_JSON_FILE MATERIAL_JSON_FILE`, and `owner-direct-begin-recover CONFIG ATTACH_ID COMMAND_ID`. `INPUT` is the existing protected Owner source input JSON; selected command and digest are explicit CLI arguments, not guessed from source files. Options/material file contents are input-only and never appear in normal result/error text. Python/Node pass them as nonempty JSON strings. All three surfaces reject simultaneous package-stage/action/kernel selection for this direct-BEGIN path.

The return type adds nullable direct BEGIN command/instance/status fields to historical attachment results; ordinary and earlier stage/orphan results retain null for those fields. This isolated facade source and its local checks do not establish installed behavior, a public release, or native Windows/macOS support. The full functional gate belongs to the frozen core runtime service test, with an installed consumer gate still required after accepted integration.
